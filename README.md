# Portal de Estudos — Trilha Ciência de Dados

Portal interativo de estudos: **de Analista de Dados a Cientista de Dados Especialista**.

🔗 **Acesse o portal:** https://matiasc19.github.io/Portal_Estudos/

## O que tem aqui

- **6 fases · 18 módulos · ~595 horas** de trilha sequencial com cursos e certificações gratuitas
- **Compilador Python interno** (Pyodide): 16 testes práticos com correção automática e dicas de ajuste
- **Players do YouTube** embutidos (Curso em Vídeo, StatQuest, 3Blue1Brown)
- **Progresso persistente** com curva de treinamento e marcos de carreira (▲ empregável · ■ núcleo completo)
- Navegação por barra lateral, conteúdo na área central e visualizador interno de links

## Como publicar (GitHub Pages)

Settings → Pages → *Deploy from a branch* → branch `main` → pasta `/ (root)` → Save.

## Observações

- Os players do YouTube exigem acesso via `https` (no `file://` ocorre o erro 153 do YouTube).
- O compilador Python baixa ~10 MB via CDN na primeira execução (depois fica em cache).
- Links de cursos apontam para páginas oficiais e podem mudar com o tempo.
